# 亡灵杀手：夏侯惇 PC

BY:B站 社会の喵

本仓库存放 Windows 游戏运行构建，不包含 Unity 工程源码。

## 下载与运行

1. 前往 [v0.1 Release](https://github.com/chsocialcats-prog/wlss/releases/tag/v0.1)，下载 **v0.1.zip**。
2. 完整解压，打开 `wlss` 文件夹。
3. 双击 `亡灵杀手：夏侯惇 BY：B站 社会の喵.exe`。

请保留同目录的 `wlss_data`、`MonoBleedingEdge`、`UnityPlayer.dll` 等运行文件，不要只移动 EXE。

游戏进度保存在 EXE 同级 `saved/`，更新或移动游戏时请保留该文件夹。此发布包不附带个人存档。具体操作见包内使用说明。

## 仓库文件

大型资源通过 Git LFS 保存。克隆仓库时需要安装 Git LFS，并执行 `git lfs pull`。普通玩家请直接下载 Release 中的 **v0.1.zip**，不要使用 GitHub 自动生成的 Source code 压缩包代替游戏包。
